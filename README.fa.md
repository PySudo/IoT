# پروژه IoT - مستندات فارسی

## 📖 مقدمه

این یک پروژه IoT (اینترنت اشیاء) است که یک راه‌حل جامع برای مدیریت دستگاه‌های هوشمند با پشتیبانی میکروکنترلر، برنامه‌ریزی پایگاه داده و عملکرد کنترل پین فراهم می‌کند.

## 🏗️ ساختار پروژه

```
IoT-main/
├── README.md           # مستندات اصلی (انتخاب زبان)
├── README.en.md        # مستندات انگلیسی
├── README.fa.md        # مستندات فارسی
├── setup.py            # تنظیمات بسته‌بندی
│
├── example/            # نمونه‌های پیاده‌سازی
│   └── core/
│       ├── buttons.py      # تولید رابط کاربری دکمه
│       ├── config.py       # پیکربندی
│       ├── database.py     # عملیات پایگاه داده
│       └── functions.py    # توابع کمکی
│
├── main_api/           # سرور REST API
│   └── core/
│       ├── config.py       # پیکربندی API
│       ├── database.py     # مدل‌های پایگاه داده
│       └── functions.py    # منطق تجاری API
│
└── MicroController/    # نرم‌افزار میکروکنترلر
    ├── main.py         # نقطه ورود اصلی
    └── functions.py    # توابع دستگاه
```

## ✨ ویژگی‌های اصلی

- **پشتیبانی میکروکنترلر**: اتصال و مدیریت دستگاه‌های ESP8266/ESP32 و مشابه
- **REST API**: API کامل برای مدیریت دستگاه
- **کنترل پین**: مدیریت GPIO از راه دور
- **مدیریت کاربر**: سیستم کاربر مدیر برای امنیت
- **یکپارچگی پایگاه داده**: تداوم داده برای حالات دستگاه

## 🚀 شروع سریع

### نصب

```bash
# نصب بسته
pip install -e .
```

### پیکربندی

1. **تنظیمات میکروکنترلر** (`MicroController/main.py`):
```python
SSID = 'نام-شبکه-WiFi-خود'
Password = 'رمز-عبور-WiFi-خود'
API_URL = 'http://آدرس-سرور-API'
API_KEY = 'کلید-API-خود'
```

2. **تنظیمات سرور API**:
- به‌روز‌رسانی پیکربندی در `main_api/core/config.py`
- تنظیم اعتبارات پایگاه داده

### اجرای پروژه

**شروع سرور API**:
```bash
python -m main_api
```

**استقرار روی میکروکنترلر**:
- بارگذاری `MicroController/main.py` و `functions.py` به دستگاه خود با استفاده از MicroPython

## 📚 اجزای پروژه

### 1. میکروکنترلر
- اتصال به شبکه WiFi
- دریافت پیکربندی‌های پین از API
- مدیریت پین‌های GPIO به‌صورت لحظه‌ای
- ارسال به‌روز‌رسانی‌های وضعیت به سرور

### 2. API اصلی
- نقاط انتهایی API RESTful برای مدیریت دستگاه
- احراز هویت مدیر
- مدیریت پیکربندی پین
- بک‌اند پایگاه داده برای تداوم

### 3. ماژول نمونه
- سیستم نمونه تولید دکمه
- نمونه‌های ساختار منو
- کنترل‌های اداری

## 🔧 پیکربندی

پارامترهای پیکربندی اصلی:

| پارامتر | مکان | هدف |
|---------|------|------|
| SSID | MicroController/main.py | نام شبکه WiFi |
| API_URL | MicroController/main.py | آدرس سرور API |
| API_KEY | MicroController/main.py | کلید احراز هویت |

## 📱 نقاط انتهایی API

نقاط انتهایی رایج برای مدیریت دستگاه:

- مدیریت کاربر مدیر
- نمایش‌های وضعیت دستگاه
- کنترل پین به‌صورت لحظه‌ای
